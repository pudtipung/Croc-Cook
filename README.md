# 🍳 มีอะไรในครัว? (What's in My Kitchen)

เว็บไซต์ช่วยค้นหาสูตรอาหารจากวัตถุดิบที่คุณมีอยู่ในครัว เพื่อลดขยะอาหาร (Food Waste) และตอบคำถามยอดฮิต **“วันนี้จะกินอะไรดี?”** ได้อย่างง่ายดาย สะดวกรวดเร็ว และอร่อยลงตัว

---

## ✨ ฟีเจอร์หลัก (Key Features)

1. **ค้นหาสูตรอาหารจากวัตถุดิบ (Ingredient Search)**:
   - ติ๊กเลือกวัตถุดิบที่มีในตู้เย็นได้หลายรายการพร้อมกัน
   - ระบบ Matching Algorithm แยกเมนูที่ **"พร้อมปรุงทันที" (Ready to Cook)** กับเมนูที่ **"ยังขาดวัตถุดิบบางอย่าง"**
   - จำแนกสถานะวัตถุดิบ 4 สีชัดเจน: มีอยู่ (เขียว), ขาดจำเป็น (แดง), เครื่องปรุงรส (เหลือง), ทางเลือกเสริม (ขาว)

2. **หน้ารวมสูตรอาหารและรายละเอียด (Recipes & Detail)**:
   - แสดงรายการสูตรอาหารทั้งหมด พร้อมตัวกรองตามหมวดหมู่
   - หน้ารายละเอียดแสดงขั้นตอนวิธีปรุงทีละข้อ ปริมาณวัตถุดิบ เวลาปรุง และจำนวนที่เสิร์ฟ
   - **ระบบนับยอดเข้าชม (View Counter)**: บันทึกยอดเข้าชมแต่ละสูตรอย่างแม่นยำ พร้อมระบบป้องกันการนับซ้ำใน Session เดียวกัน

3. **หน้าแรกและสูตรอาหารแนะนำยอดนิยม (Home & Popular Recipes)**:
   - จัดอันดับสูตรอาหารแนะนำตามยอดเข้าชมยอดนิยมจากฐานข้อมูลจริง
   - สรุปตัวเลขสถิติในระบบ (จำนวนสูตร, วัตถุดิบ, หมวดหมู่)

4. **หมวดหมู่อาหาร (Categories)**:
   - รวมหมวดหมู่อาหาร (ผัด, ต้มและแกง, ทอด, ยำ, น้ำพริก, จานเดียว) พร้อมนับจำนวนสูตรอาหารในแต่ละหมวด

5. **ระบบจัดการหลังบ้าน (Admin CRUD Panel)**:
   - เข้าสู่ระบบปลอดภัยด้วย Password Hash (Bcrypt) และ CSRF Token Protection
   - **จัดการสูตรอาหาร**: เพิ่ม/แก้ไข/ลบสูตรอาหาร พร้อมระบบเลือกวัตถุดิบแบบไดนามิก ระบุปริมาณ หน่วยวัด และความจำเป็น
   - **จัดการวัตถุดิบ**: เพิ่ม/แก้ไข/ลบวัตถุดิบ และจัดกลุ่มประเภทวัตถุดิบ
   - แดชบอร์ดสรุปภาพรวมข้อมูลในระบบ

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Backend**: PHP 8.x (ใช้ PDO และ Prepared Statements ป้องกัน SQL Injection)
- **Database**: MySQL / MariaDB (UTF-8 mb4)
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS), Bootstrap 5.3.3, Bootstrap Icons
- **Web Server**: Apache (XAMPP)

---

## 🚀 ขั้นตอนการติดตั้งและเปิดใช้งาน (Installation)

### 1. ติดตั้ง XAMPP
- ดาวน์โหลดและติดตั้ง [XAMPP](https://www.apachefriends.org/)
- เปิด XAMPP Control Panel และกด **Start** ที่โมดูล **Apache** และ **MySQL**

### 2. ติดตั้งโค้ดโปรเจกต์
- นำโฟลเดอร์โปรเจกต์ `whats-in-my-kitchen` ไปวางไว้ที่:
  ```
  C:\xampp\htdocs\whats-in-my-kitchen
  ```

### 3. นำเข้าฐานข้อมูล (Import Database)
1. เปิดเบราว์เซอร์ไปที่ `http://localhost/phpmyadmin/`
2. สร้างฐานข้อมูลใหม่ชื่อ: `whats_in_my_kitchen` (Collation: `utf8mb4_unicode_ci`)
3. เลือกแถบ **Import (นำเข้า)**
4. เลือกไฟล์ `database/schema.sql` จากในโปรเจกต์ แล้วกด **Go (ดำเนินการ)**

### 4. เข้าใช้งานเว็บไซต์
- **หน้าเว็บสำหรับผู้ใช้ทั่วไป**:
  ```
  http://localhost/whats-in-my-kitchen/
  ```
- **ระบบหลังบ้านผู้ดูแลระบบ (Admin)**:
  ```
  http://localhost/whats-in-my-kitchen/admin/login.php
  ```
  - **ชื่อผู้ใช้ (Username)**: `admin`
  - **รหัสผ่าน (Password)**: `admin123`
